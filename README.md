# Культура, наука и образование России 1990-х годов

Статическая одностраничная digital exhibition для учебного выступления по истории.

## Как открыть

Откройте `index.html` в браузере. Сайт не требует сборки и backend.

## Где редактировать

- `script.js` — структура разделов, тексты, timeline, карточки и ссылки на изображения.
- `styles.css` — визуальный стиль, сетка, адаптивность и модальное окно.
- `index.html` — базовый каркас страницы.

## Принципы

- один минималистичный hero на архивной фотографии;
- четыре сбалансированных раздела без превращения отдельных объектов в символ всей эпохи;
- простые карточки и модальное окно вместо сложного музейного интерфейса;
- реальные источники и короткие подписи к визуальным материалам.
