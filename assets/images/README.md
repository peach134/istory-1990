# Images

Сайт сейчас использует открытые изображения Wikimedia Commons через `Special:FilePath`.
Так проще сохранить историческую атрибуцию и не хранить спорные копии в учебном проекте.

Если нужно сделать полностью офлайн-версию, скачайте выбранные изображения в эту папку и
замените вызовы `commonsFile(...)` в `script.js` на локальные пути вида:

```js
image: "assets/images/example.jpg"
```

У каждого экспоната уже есть подпись и ссылка на страницу источника.
